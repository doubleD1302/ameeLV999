# Rủi ro và cách xử lý

| Rủi ro | Tín hiệu sớm | Hành động |
|---|---|---|
| Scope phình | Mỗi prompt thêm một hệ thống | Khóa P0/P1; đưa ý mới vào backlog P3 |
| AI asset lệch | Golden set không đặt cạnh nhau được | Duyệt12 asset trước batch, khóa reference |
| Puzzle không giải được | Chỉ có lời khẳng định của AI | Solver/certificate và playtest |
| Save mất/dup | State sửa ngoài reducer | Transaction, claims, migration fixtures |
| PWA offline giả | Chỉ test khi tab còn mở | Cold launch airplane mode |
| Context drift | Task sửa stack/ID không lý do | AGENTS/context routing/ADR/handoff |
| Năng suất art thấp | Mỗiframe cần sửa nhiều | Giảm animation, ưu tiên silhouette vàreuse |
| Game nhàm | Chỉ bấm đợi không có chọn lựa | Playtest phiên5–15 phút, thêm decor/story/puzzle phù hợp |
| Bundle quá lớn | Master artwork vào public | Normalize/atlas/audio budgets, phase install rõ |

Chủ dự án quyết định thẩm mỹ và ưu tiên; AI cung cấp bằng chứng cùng đề xuất cụ thể. Không dùng chữ “hoàn hảo” thay cổng nghiệm thu.
