# Prompt khởi tạo repo

Hãy bắt đầu T001 cho Blooming Home trong thư mục này. Đây hiện là bộ tài liệu, chưa có game. Đọc AGENTS.md, TECH_STACK.md, FOLDER_STRUCTURE.md và REFERENCE_SOURCES.md trong docs/10_tech/.

Mở tài liệu Phaser/Vite chính thức và xác minh phiên bản/template hiện được hỗ trợ tại thời điểm làm task. Dùng template Phaser + TypeScript + Vite tương thích; chạy scene + texture + input + resize smoke test, rồi pin dependency chính xác, tạo lockfile và ghi Node version. Dùng HTML/CSS cho UI; không tự thêm React/backend.

Tạo cấu trúc src theo kiến trúc, scene nhỏ có nền/placeholder, input tap/click và resize. Tạo các npm script dev, typecheck, lint, test, test:e2e, validate:data, build và preview, kèm hướng dẫn chạy. Tạo một domain smoke test có ý nghĩa và một browser smoke test mở scene. Chạy các lệnh đã tạo trong môi trường, ghi rõ lệnh và giới hạn kiểm chứng.

Giữ docs/data/schemas/prompts trong repo. Không sửa các catalog để làm build pass. Cập nhật README, CURRENT_STATUS và task T001 khi đủ DoD. Chưa publish.
