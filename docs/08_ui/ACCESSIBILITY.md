# Khả năng tiếp cận

Chữ chính≥16 CSSpx, tùy chọn tăng125/150%; body contrast≥4.5:1, chữlớn≥3:1. Label bắt buộc cho icon không hiển nhiên. Màu luôn kèm hình/ký hiệu, đặc biệt hoa logic và pipe.

Tất cả modal có focus trap và return focus; keyboard mở/đóng; visible focus. Live region thông báo reward một lần, không đọc từng frame timer. Không đặt toàn giao diện trong canvas mà không có cách thay thế.

Puzzle không timer bắt buộc. Hint/assist sẵn, no-cost; memory dùng silhouette+label, hidden object có outline gợi ý; audio clue có visual equivalent. Giảm chuyển động tắt screenshake,bounce,particles dày, lightning flashes.

Tắt music/SFX riêng; mute persist. Có pause cho hành vi phản xạ fishing, chếđộ thưgiãn không phạt main story. Không yêu cầu kéo thả chính xác nếu có lựa chọn tap-to-place.

QA cần người thử bằng keyboard, text zoom, muted audio và một vòng puzzle không phân biệt màu. Mục tiêu AA cho UI web có thể kiểm, không tuyên bố chứng nhận khi chưa audit.
