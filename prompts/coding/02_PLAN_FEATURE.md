# Prompt lập kế hoạch tính năng

Mục tiêu: lập kế hoạch cho task {{TASK_ID}} / {{FEATURE}}. Đây là lượt lập kế hoạch, chưa sửa source.
Đọc AGENTS.md, đặc tả hệ thống, data/schema liên quan và code đang có.

Trả ra: trạng thái hiện tại; hành vi đích; command/state/data cần đổi; file sẽ chạm; edge cases; kiểm chứng; ảnh hưởng save/offline; các bước nhỏ theo thứ tự. Chỉ hỏi các quyết định còn thiếu thật sự. Giải thích nếu task có thể dùng module có sẵn. Không đề xuất framework mới chỉ để làm một màn.
