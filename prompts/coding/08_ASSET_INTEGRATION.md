# Prompt tích hợp asset đã tạo

Tích hợp batch {{ASSET_BATCH}} từ các file đã có. Đọc ART_BIBLE, ASSET_SPECS, ASSET_PIPELINE và registry. Xem từng asset trước khi duyệt; kiểm alpha, camera, anchor, frame count, naming và budget.

Chuẩn hóa/pack deterministic, cập nhật registry hash/file/status với bằng chứng QA. Chỉ approved assets đưa vào manifest runtime. Kiểm trong scene ở kích thước thật, nền sáng/tối và PWA cache. Nếu một file không đạt, liệt kê để sửa; không tự ghi approved toàn batch.
