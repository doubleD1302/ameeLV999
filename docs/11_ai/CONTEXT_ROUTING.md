# Nạp đúng ngữ cảnh cho mỗi task

Luôn đọc AGENTS.md, SCOPE.md, DECISIONS.md và CURRENT_STATUS.md; sau đó chỉ nạp nhóm liên quan. Đọc code hiện tại trước khi tạo giải pháp mới. Không paste toàn bộ bộ tài liệu vào một prompt.

| Task | Tài liệu bổ sung |
|---|---|
| Bootstrap | TECH_STACK, FOLDER_STRUCTURE, README, REFERENCE_SOURCES |
| Luật trồng/bán | FLOWERS, SHOP_ECONOMY, ECONOMY_BALANCE, COMMANDS_EVENTS, data liên quan |
| Save/offline | SAVE_SYSTEM, SAVE_MIGRATIONS, MULTITAB, TIME_AND_IDLE, OFFLINE_PWA, fixtures |
| Một puzzle | ENGINE_CONTRACT, đặc tả engine, DIFFICULTY_HINTS, puzzles.json, PUZZLE_TESTS |
| UI | SCREEN_SPECS, INPUT_RESPONSIVE, ACCESSIBILITY, localization, domain selectors |
| Asset | ART_BIBLE, ASSET_SPECS, golden references, category prompt, registry request |
| Story | STORY_BIBLE, CHAPTERS, DIALOGUE_STYLE, flags của quest |
| Release | DEFINITION_OF_DONE, RELEASE_RUNBOOK, DEVICE_MATRIX, QA_REPORT |

Khi context bị rút gọn, đọc CURRENT_STATUS và handoff task trước. Nếu trạng thái docs khác repo, ghi rõ chênh lệch và kiểm bằng lệnh; không tự tin rằng task xong vì lịch sử chat nói vậy.
